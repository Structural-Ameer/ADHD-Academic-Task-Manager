# ADHD Academic Task Manager

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/Structural-Ameer/ADHD-Academic-Task-Manager.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ADHD-Academic-Task-Manager
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```

## Features
- Task management: Easily create, edit, or delete tasks.
- Due dates: Set and manage due dates for tasks.
- Priority levels: Assign priority to tasks for better organization.
- Notifications: Get reminders for upcoming tasks.
- User-friendly interface: Intuitive design for a smooth user experience.

## Usage Guide
1. Start the application:
   ```bash
   npm start
   ```
2. Open your browser and go to: `http://localhost:3000`
3. Create your first task by clicking on the "Add Task" button.
4. Manage your tasks by clicking on them to edit or remove.

## Development Setup Instructions for Windows Users
1. Install [Node.js](https://nodejs.org/) (includes npm).
2. Install Git from [git-scm.com](https://git-scm.com/).
3. Clone the repository as detailed in the Installation Instructions.
4. Open your terminal (Command Prompt or PowerShell), navigate to the project directory, and run:
   ```bash
   npm install
   ```
5. To run the application, use:
   ```bash
   npm start
   ```

Enjoy managing your academic tasks!
